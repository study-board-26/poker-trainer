# ポーカー・トレーナー

テキサスホールデムの GTO 練習アプリ。HTML 1ファイルだけで動きます。

- 1手ごとに「その状況で何をどれくらいの頻度で選ぶべきか」を採点します
- EVモデルは自前の厳密解ソルバー（リバー・ターン・フロップの CFR+）と照合して較正してあります
- 浅いスタックはプッシュ／フォールドの均衡を自分で解いて使います
- 持ちチップは端末ごとに保存され、尽きるまで続けられます
- スマホはホーム画面に追加すると全画面のアプリとして開けます

`index.html` を開くだけで動きます。ただし端末内のファイルを直接開くと
持ちチップが保存されないため、`https` で配信してください。
